# 心電図道場（ECG-dojo）

KenMaP の中のアプリです。急性期の看護師向けの、段位制の心電図クイズ。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の見た目 |
| `app.js` | 画面の切り替え・クイズ・進み具合の保存 |
| `ecg.js` | 波形を計算で描く仕組み・モニター・音 |
| `data/shiro.json` | **白帯の問題・解説・稽古の説明文（監修用）** |
| `data/cha.json` | **茶帯の問題・解説・稽古の説明文（監修用）** |
| `data/kuro.json` | **黒帯の問題・解説・稽古の説明文（監修用）** |

## 監修のしかた（data フォルダの各 JSON）
- `lessons` … 稽古の説明文。`parts` の `text` が、タップしたときに出る解説です。
- `questions` … 試合・昇段試験の問題。
  - `question` 問題文 / `choices` 選択肢（4つ）/ `answer` 正解の番号（**0から数える**。1つ目が0）
  - `explanation` 解説
  - `reviewed` 監修が済んだら `true` に
  - `memo` 監修メモ（画面には出ません）
  - `strip` があると、記録紙の波形を問題に表示します（`hr` 心拍数, `seconds` 秒数）
- 問題を増やすときは `{ … }` を1つコピーして、`id` を `shiro-q06` のように変えてください。
- 合格ラインは `passRate`（0.8 = 80%）。

※ JSON は「,」や「"」が1つ抜けるだけで読み込めなくなります。直したあとは公開ページで表示を確認してください。
※ パソコンで index.html をダブルクリックして開くと、JSON を読み込めずエラー表示になります（公開後のページでは正常に動きます）。

## 公開（KenMaP リポジトリへのアップロード）
`ECG-dojo` フォルダごと、KenMaP リポジトリの一番上にアップロードします。
内容を更新したら、KenMaP の `sw.js` の `VERSION` を上げてください。
